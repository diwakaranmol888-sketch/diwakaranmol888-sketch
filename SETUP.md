# Setup (5 minutes)

1. On GitHub, create a **public** repo named exactly like your username (e.g. `rajesh-kumar/rajesh-kumar`). Tick "Add a README".
2. Upload everything from this folder to that repo, keeping the folder structure:
   `README.md`, `assets/header.svg`, `assets/divider.svg`, `.github/workflows/snake.yml`.
3. Open `README.md` and replace every `YOUR_USERNAME`, `YOUR_LINKEDIN`, `YOUR_EMAIL` and the `whoami` block. Also open `assets/header.svg` and change `YOUR NAME`.
4. Repo -> Settings -> Actions -> General -> Workflow permissions -> select **Read and write permissions** -> Save.
5. Repo -> Actions tab -> "Generate Snake Animation" -> **Run workflow**. Wait about 1 minute; it creates an `output` branch holding the snake SVGs.
6. Refresh your profile. The snake appears.

Tips
- The snake only looks impressive if your contribution graph has green squares. Commit regularly.
- Pin your 6 best repos on your profile and give each a clear description.
